That one snapshot feeds all four consumers (scoped count, the `+ACTIVE`-elsewhere footnote, the alternate-slug candidate, the recent-task fallback), replacing the former second `task +ACTIVE export`. Ladder: slug matches → `TASK_SCOPE=project`/`PROJECT_CONFIDENCE=high`; else the **git remote's** repo name (local, no network, only evaluated in the failing case) → `remote-name` + `PROJECT_RESOLVED=`; else `all-projects-fallback` with `RECENT_TASK_*` rows inside `--recent-days` (default 2). `OPEN_TASKS` stays an **integer** in every branch — `OPEN_TASKS=unknown` was rejected because three call sites do `-gt` arithmetic on it (`session-survey.sh` ×2, `session-spinup-nudge.sh`) and would all silently evaluate false; the uncertainty lives in the separate `TASK_SCOPE`/`PROJECT_CONFIDENCE` keys.
