| `external-pr-merge-guard.sh`'s structural awk scanner had four defect classes, all of which let a **real merge of an external PR** through. (1) A **fail-OPEN selector-shape gate**: once the command word was structurally established as `gh pr merge`, an argument that did not match a narrow selector whitelist turned the statement back into an ALLOW — reachable purely by a contributor-chosen branch name (`_wip`, `feat/a,b`, `feat/100%-done`), by a redirection bash strips before `gh` sees argv (`gh pr merge 2>/dev/null 2231`), or by a stdin redirect (`xargs -n1 gh pr merge < prs.txt`). (2) **Wrapper blindness**: the stripper skipped only flags and bare durations, so a wrapper flag taking a SEPARATE value (`sudo -u ci`, `env -C dir`) left a non-command word at the head, and `find -exec` / `parallel` / `watch` / `script` / `uv run` were not treated as wrappers at all. (3) **Missing command positions**: backticks were not statement separators, operators inside nested script text did not separate statements there, and a heredoc fed to a shell (`bash <<EOF`) was never scanned as script text. (4) The issue's own headline false positive survived for the api half — the `pulls/N/merge` route matched under **any** command word, so `rg …/pulls/2231/merge docs/` was denied with a message that misdiagnosed it. | The shape gate is **deleted**: the command word is already known structurally at that point, so the statement IS a merge whatever its argument looks like, and an unresolvable selector falls through to the author check, which denies. Redirections are skipped when picking the selector so the denial names the right PR. Wrappers now also scan the rest of the statement (on the MASK, so quoted prose behind a wrapper stays prose), and `nest` (is this quoted string script text?) is computed from the EFFECTIVE command word, making `sudo -u ci bash -c "…"` a shell invoker. The api route now requires a command word that can actually call it (`gh`/`curl`/`wget`/`http`/`xh`/`hurl`). Net: 20 real merge forms flip ALLOW→DENY, 4 mention forms flip DENY→ALLOW.
