| `git-plugin/skills/git-triage/scripts/git-triage.sh` packed the full PR `body` as the 8th field of the per-PR categorization `@tsv` row. Bot (Dependabot/Renovate) PR bodies are large multi-line markdown with embedded tabs, so on read every enum column slid right: `PR_<n>_REVIEW` held the worst-check conclusion, `PR_<n>_WORST_CHECK` held the entire ~9 KB body, and `categorize_pr` was fed garbage → fell through to `uncategorized` for **every** PR. On a 10-PR repo the script also blew past the 25 KB Read cap (92.8 KB output), making Step 4 of the skill non-functional for any repo whose PRs have non-trivial bodies.
