Decision (Lauri, 2026-11-01): an in-file marker `<!-- skill-size-exception: <pinning check> -->`. The gate skips the WARN band for a marked skill (the 26,000-char ERROR still applies) and the selector skips it; the regex is single-sourced as `SKILL_SIZE_EXCEPTION_RE` in the gate and read by the selector, which exits 2 if the line is missing. A marker with an empty or whitespace-only check name does not exempt, and its WARN says so. The ten skills carry markers naming their pin | `scripts/tests/test-plugin-compliance-skill-size.sh` (marked over-size fixture silent; empty and blank markers still WARN with the reason; a marked >26000 fixture still ERRORs) and `scripts/tests/test-select-split-candidates.sh` guard P (marked skipped, empty-marker and unmarked selected, explicit marked path skipped, gate without the regex exits 2).
