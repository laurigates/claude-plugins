| `configure-formatting.sh` decided `CI_FORMAT` with `grep -qE "biome format\|ruff format\|cargo fmt\|prettier"` over `.github/workflows/*`, which misses the **idiomatic** Biome setup two ways. (1) In Biome 2.x `biome check` is the combined command — formatter + linter + import sorting in one pass — and `biome ci` is its CI-oriented variant; only the narrower format-only `biome format` was matched, so a repo whose merge gate genuinely enforces formatting reported as having no CI format check. (2) The scan looked for the tool invocation **in the workflow**, but the common shape is a workflow step running `bun run lint` with the real command in `package.json`'s `scripts` — so even a `biome format --write` went undetected through that one hop. Reported against a repo whose `lint.yml` runs `bun run lint` → `biome check .`: the probe emitted `BIOME=true FORMAT_SCRIPT=true CI_FORMAT=false`, and the false negative is silent — the operator is told to add a CI format check that already exists, and `/configure:formatting` would happily add a duplicate. | Split the command pattern out as `fmt_cmd_re` with `biome check` and `biome ci` added, and `biome lint` deliberately **absent** (lint-only — it does not format). Added exactly **one** level of package-script indirection: workflow steps matching `(bun\|npm\|pnpm\|yarn) run <s>` or `yarn <s>` are resolved against `package.json`'s `scripts.<s>` via `jq` and matched against the same pattern. One level only — a script calling another script is out of scope, so the resolver cannot recurse. `jq` is the house style in `configure-plugin` (`configure-ux-testing` already depends on it) but is used **guarded** here rather than as a new hard requirement: an absent/unparseable/`scripts`-less `package.json`, or a missing `jq`, degrades silently to the direct scan (no stderr, exit 0), so the pre-existing behaviour is never worse than before. The `grep` match on a script body uses a here-string, never `printf \| grep -q`, to avoid the #1744 SIGPIPE-under-`pipefail` race. | `configure-plugin/skills/configure-formatting/scripts/tests/test-configure-formatting.sh` cases 4–10 (27 assertions) **EXECUTE** the probe rather than grepping the script — the #1417 → #1819 lesson, and it bites specifically here: a naive grep for `biome format` also matches inside `biome format --write`, so a grep-based gate passes against the unfixed script. **The negative controls carry as much weight as the positives**, since a probe hardwired to `true` would satisfy every case 4/5 assertion: `biome lint` must NOT set it (directly AND through indirection), a depth-2 script chain must NOT resolve, and a project with no workflows must stay `false`.
